# Introduction
This section contains the main code that was used to make the project work. The robot follows a white line on a black background until all three sensors detect white. Then, the robot uses the robotic arm to push an object. After that, the robot makes a U-turn and follows the line back to the starting line.

The robot is equipped with a heartbeat LED and an MP3 module that announces the start and end of the course. It is also equipped with an ultrasonic sensor to detect objects in its trajectory.

An organigram is also included to provide a better understanding of the structure of the code.
